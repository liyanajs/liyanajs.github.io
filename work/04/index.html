TIC TAC TOE

ALGORITHM DESIGN / CROSS-PLATFORM LOGIC

Logic as a Service: This project served as a technical deep-dive into behavioral algorithm design. Originally developed as a Python command-line tool, I engineered a decision-making engine that evaluates board states to prioritize strategic 'Attack' and 'Defense' moves.


To demonstrate cross-platform versatility, I performed a full Algorithm Port, translating the Python backend into this responsive JavaScript interface. This transition highlights my ability to maintain logical integrity while adapting code for modern web environments.

Algorithm Porting & Logic Translation

The core challenge of this project was the transition from a Terminal-based Python environment to a functional Web GUI. While the game logic was successfully engineered in Python, web browsers cannot execute Python scripts natively for user interfaces.


To solve this, I performed a full Algorithm Port. I translated the "Attack and Defense" logic I built in Python into JavaScript. This process allowed the backend decision-making engine to communicate seamlessly with the HTML grid, transforming a command-line script into a responsive, interactive web application.

Strategic AI Engineering

A primary goal was to move beyond random movements and create an AI that simulates human-like prioritization. I mastered conditional logic in Python to create a tiered response system.


The AI evaluates the board in three distinct phases: first, it scans for an immediate winning move (Attack); if none exist, it identifies and blocks player threats (Defense); finally, it utilizes a random fallback for neutral states. Implementing this "Try, Check, Undo" logic was my first step into understanding complex state-based algorithms.
